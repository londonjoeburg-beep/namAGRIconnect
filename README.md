# 🌾 AgriConnect Namibia

## Connecting Namibian Farmers to Markets and Each Other

### 🚀 Live Demo
[https://agri-connect-namibia.up.railway.app](https://agri-connect-namibia.up.railway.app)

### 📋 Features
- ✅ User Registration & Login
- ✅ Product Posting with Images
- ✅ Product Browsing & Search
- ✅ Community Forum with Likes & Dislikes
- ✅ Weather Updates
- ✅ Market Prices (Admin + Automated)
- ✅ Admin Dashboard
- ✅ Responsive Design

### 🛠️ Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** SQLite3
- **Deployment:** Railway
